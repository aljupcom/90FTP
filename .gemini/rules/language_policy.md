# قواعد لغة واجهة التطبيق وسجل التغييرات (UI & Release Language Policy)

تحدد هذه الوثيقة القواعد الصارمة والملزمة للغة واجهة المستخدم وسجلات التحديث لتطبيق 90FTP:

---

## 1. الإلزام الكامل باللغة الإنجليزية في واجهة المستخدم (100% English UI Standard)
- **منع استخدام اللغة العربية في واجهة التطبيق قطعياً**: نظراً لأن تطبيق 90FTP تطبيق تقني واجهته مبنية بالكامل باللغة الإنجليزية، يُمنع منعاً باتاً كتابة أو دمج أي نصوص عربية داخل واجهة المستخدم (UI)، بما في ذلك:
  - عناوين وأزرار ومحتويات النوافذ المنبثقة (Modals & Dialogs مثل نافذة التحديث، نافذة الإعدادات، نافذة حول، نافذة الأدوات).
  - رسائل التنبيه والحالة ومؤشرات التغييرات (Status messages, banners, tooltips, validation alerts).
  - القوائم وأشرطة الأدوات والتبويبات (Menus, toolbar buttons, tabs, context menus).
- **منع التناقض والازدواج اللغوي**: يُمنع منعاً باتاً وضع نصوص مختلطة مثل `(Software Update) تحديث البرنامج` أو `Unsaved changes (هناك تغييرات غير محفوظة)`. كل النصوص يجب أن تكون إنجليزية احترافية نقية وموحدة (Professional English only).

---

## 2. سجل التغييرات ونصوص الإصدارات (Clean English Release Notes)
- سجل التغييرات في نافذة التحديث (What's New) وفي إصدارات GitHub يجب أن يقتصر **فقط** وبدقة على الميزات والإصلاحات الفعلية باللغة الإنجليزية دون أي نصوص إعلانية أو تفاصيل مكررة.
- **حظر إضافة أقسام ثابتة غير مطلوبة**: يُمنع تضمين فقرات ثابتة مثل `Enterprise Security` أو تفاصيل البصمات والمفاتيح ما لم يطلب المستخدم ذلك صراحة.
