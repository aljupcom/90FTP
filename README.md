# 90FTP - Modern Site Manager 🚀

تطبيق مكتبي خفيف وسريع وعصري لإدارة مواقع الويب وخوادم الملفات عبر بروتوكولات **FTP / FTPS / SFTP (SSH)**، مستوحى من بنية برنامج **WinSCP** الكلاسيكية ومبني بتصميم عصري وأنيق وتقنيات **Rust + Native WebView**.

---

## ✨ المميزات الرئيسية (Key Features)

1. **واجهة مزدوجة عصرية (Dual-Pane Explorer):**
   - **اللوحة اليسرى:** مستكشف ملفات الحاسوب المحلي (Local PC) مع دعم التنقل بين الأقراص (C:\, D:\...).
   - **اللوحة اليمنى:** مستكشف ملفات الخادم والموقع (Remote Website) مع قراءة الصلاحيات والمسار الحالي.
   - **أزرار النقل المركزية:** رفع فوري للموقع (➔) أو تنزيل للجهاز (⬅).

2. **دعم البروتوكولات المتعددة (Protocols):**
   - **SFTP (SSH):** اتصال آمن ومشفر عبر المنفذ 22 مع دعم صلاحيات Linux والمصادقة.
   - **FTP & FTPS:** اتصال بروتوكول نقل الملفات الكلاسيكي والمشفر.

3. **محرر كود مدمج وسريع (Built-in Quick Code Editor):**
   - بالنقر المزدوج على أي ملف نصي أو برمجي (مثل `index.php`, `.env`, `style.css`, `script.js`, `wp-config.php`).
   - تحرير فوري ودعم اختصار **`Ctrl + S`** للحفظ والرفع المباشر إلى الخادم دون الحاجة لبرامج خارجية.

4. **مدير الصلاحيات (CHMOD Permissions Manager):**
   - واجهة رسومية سهلة لتعديل صلاحيات الملفات والمجلدات (Read, Write, Execute للمالك والمجموعة والعموم).
   - حساب تلقائي للقيمة الرقمية (مثل `0755` أو `0644`) وتطبيقها فوراً.

5. **مدير المواقع والجلسات (Saved Sites / Session Manager):**
   - حفظ بيانات خوادم ومواقع متعددة مع أسماء مخصصة والاتصال بنقرة واحدة.

6. **شريط الأوامر وسجل العمليات الحي (Activity Console Log):**
   - شاشة عرض حية تسجل ردود الخادم وأوامر الاتصال ومسار كل عملية نقل بالوقت الفعلي.

---

## 🛠️ البنية التقنية (Architecture & Tech Stack)

- **المحرك الخلفي (Backend):** لغة **Rust** فائقة السرعة والأمان وحماية الذاكرة.
  - بروتوكول FTP: مكتبة `suppaftp`.
  - بروتوكول SFTP: مكتبة `ssh2` الأصلية عبر WinCNG.
  - نظام الملفات المحلي: `std::fs` مدمج مع حساب التواريخ والحجم.
- **الواجهة الرسومية (Native Desktop UI):**
  - نافذة مكتبية مستقلة عبر `tao` و `wry` (تعتمد على محرك WebView2 المدمج في ويندوز دون الحاجة لفتح المتصفح).
  - تصميم أنيق بتقنية **Glassmorphism / Dark Modern UI** متناسق ومريح للعين.

## 🚀 طريقة التشغيل (How to Run)

### 1. التشغيل المباشر:
يمكنك ببساطة تشغيل الملف التنفيذي الجاهز مباشرة بنقرة مزدوجة:
```text
C:\Users\aljailane\Desktop\Apps\90FTP\90FTP.exe
```

### 2. التشغيل عبر سطر الأوامر (للمطورين):
```powershell
cargo run
```

## 📁 هيكل المشروع (Project Structure)

```text
90FTP/
├── 90FTP.exe               # الملف التنفيذي المباشر للتطبيق
├── Cargo.toml              # ملف التبعات والإعدادات
├── src/
│   ├── main.rs             # نقطة الدخول وإنشاء النافذة وربط الـ IPC
│   ├── app_state.rs        # معالج طلبات الواجهة والاتصال
│   ├── models.rs           # هياكل البيانات (الملفات، الجلسات، الرسائل)
│   ├── local_fs.rs         # مستكشف ومعالج الملفات المحلية
│   ├── ftp_client.rs       # عميل ومحرك FTP / FTPS
│   ├── sftp_client.rs      # عميل ومحرك SFTP (SSH)
│   ├── remote.rs           # توحيد جلسات الاتصال البعيدة
│   ├── sessions.rs         # مدير حفظ واسترجاع بيانات المواقع
│   └── ui/
│       └── index.html      # واجهة المستخدم والمحرر المدمج (HTML/CSS/JS)
```
