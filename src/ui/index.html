About 90FTP
90FTP Desktop Edition
Modern Site Manager & Asynchronous File Transfer Engine
Version 0.0.0.55 (Windows x64) Release Channel: Official
90FTP is a high-performance, asynchronous desktop SFTP, FTPS, and FTP client engineered in Rust for developer velocity, multi-gigabit throughput, and secure remote infrastructure administration.
Runtime Environment
Target Platform: Microsoft Windows (x86_64-pc-windows-msvc)
Core Architecture: Rust Tokio Async Runtime + Multi-thread Workers
UI Engine: Microsoft Edge WebView2 Evergreen + Tao Host
Encrypted Vault: AES-256-GCM Hardware Accelerated (Ring)
Storage Directory: %APPDATA%\90FTP
Core Protocols & Modules
Module Protocol / Spec Engine Engine
SFTP SSH-2.0 / SFTP v3 (Ed25519, ChaCha20) russh 0.45 async
FTPS / FTP RFC-959 & RFC-4217 (Explicit/Implicit TLS) suppaftp 5.3 + rustls
Cryptography AES-256-GCM / PBKDF2 / SHA-256 ring & native crypto
Terminal ANSI/VT100 Remote Shell Streaming PTY Bridge
Icons Core Monochromatic Vector SVG Suite Feather Icons
